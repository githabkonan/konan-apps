social-autopost

Scheduled publishing of my own promotional videos

social-autopost is a personal automation tool I built to publish the short promotional videos for my own mobile apps to my own connected social channels on a fixed daily schedule, using each platform's official API.

What it does

  • Stores a small queue of short videos that promote my own published mobile apps.
  • On a fixed schedule (3 times per day) it uploads the next video to my own connected channels.
  • It runs unattended so I do not have to upload the same promotional clips by hand every day.

How it uses the YouTube Data API

With my explicit authorization, the tool uses the YouTube Data API v3 youtube.upload scope to upload videos to my own YouTube channel only. It does not read, modify, or access any other user's data, and it is used solely by me, the developer/owner.

Who it is for

This is a single-operator tool used only by its developer to manage the developer's own marketing content. It is not a public product and does not onboard other users.
