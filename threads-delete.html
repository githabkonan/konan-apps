What this application stores

social-autopost is a single-operator automation tool. It stores exactly one item derived from Threads: an OAuth access token for the operator's own Threads profile, held in a permission-restricted file on the operator's own machine. It maintains no database, no server, and no copies of any other person's data.

How to delete it

  • Open your Threads profile settings and remove social-autopost from connected applications (Settings → Website permissions → Apps and websites). This immediately invalidates the stored token.
  • Alternatively, email konakonan822@gmail.com with the subject "Threads data deletion". The stored token file is deleted and confirmation is sent within 7 days.

Retention

Nothing is retained after revocation. Content the application published to the operator's own Threads profile remains under the operator's control and can be deleted from Threads directly.
